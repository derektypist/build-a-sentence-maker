# Build a Sentence Maker

Create different words by assigning different words to different variables.

## UX

[Build a Sentence Maker User Stories](https://www.freecodecamp.org/learn/full-stack-developer/lab-sentence-maker/build-a-sentence-maker)

## Technologies

Uses JavaScript.

## Deployment

Copy `script.js` into a text editor, such as Notepad.  In `Node.js` command prompt type the command `node script.js` and press enter.
